# Contatos auxiliares

O tipo `contact` do plugin `gastro-clinic` mantém contatos administrativos auxiliares no workspace. O nome é obrigatório; e-mail, telefone, endereço e observação são opcionais. O e-mail usa o controle nativo de formato e o número de endereço aceita somente inteiros, conforme os controles observados.

Os campos pessoais são protegidos antes de gravar. O registro tem estados ativo/inativo e histórico versionado do Orbit; não há exclusão física nem vínculo automático com pessoa atendida. A tela de cadastros usa a extensão de registros existente.

Dados demonstrativos ROOT são fictícios e somente de leitura. Não envie comunicações a partir desse cadastro.
