| Logs | 🟢 **Baixa** | Padrão consolidado; pub/sub adiciona moderada complexidade |

## 5. Lacunas Identificadas

### 🔴 Lacunas Críticas (alto impacto no negócio)

| # | Lacuna | Impacto | Recomendação |
|---|--------|---------|--------------|
| 1 | **Autenticação e Autorização (IAM)** | Sem sistema de login, papéis ou permissões de usuário identificado | Implementar autenticação (OAuth2/SSO) + RBAC com papéis (admin, dev, viewer) |
| 2 | **Multi-tenancy / Organizações** | Sem isolamento entre equipes ou organizações | Adicionar conceito de organização/workspace com isolamento de dados |
| 3 | **Integrações Externas** | Sem conexão com Jira, GitHub, GitLab, Slack, etc. | Implementar camada de integrações via webhooks e APIs oficiais |
| 4 | **Auditoria e Compliance** | Contratos têm changelog, mas não há trilha de auditoria global | Log de auditoria centralizado com "quem fez o quê e quando" |
| 5 | **Gestão de Custos por Equipe** | Cost Guard existe por tarefa, mas não há visão por equipe/organização | Dashboard de custos com breakdown por equipe, projeto e modelo |

### 🟡 Lacunas Importantes (impacto moderado)

| # | Lacuna | Impacto | Recomendação |
|---|--------|---------|--------------|
| 6 | **Onboarding de Projetos** | Fluxo de primeiro uso não está definido | Wizard de onboarding: conectar repo → scan → entrevista → backlog |
| 7 | **Notificações Avançadas** | Sub-jobs não notificam (Regra 9), mas não há sistema de notificações robusto | Sistema de notificações multi-canal (in-app, email, Slack) com preferências |
| 8 | **Dashboards e Relatórios** | Dados existem (custos, cache, hits), mas não há visualização consolidada | Dashboards com métricas: velocity, custos IA, cobertura RAG, cache savings |
| 9 | **Busca Global** | Sem mecanismo de busca transversal (projetos, tarefas, wiki, contratos) | Busca full-text com filtros por tipo de entidade |
| 10 | **Versionamento de Contratos** | Changelog existe, mas não há rollback ou comparação de versões | Diff visual entre versões + capacidade de rollback |
| 11 | **Multi-repositório** | Não há evidência de suporte a múltiplos repositórios por projeto | Permitir vincular N repositórios a um projeto com indexação unificada |

### 🟢 Lacunas Menores (bom ter)

| # | Lacuna | Impacto | Recomendação |
|---|--------|---------|--------------|
| 12 | **Testes Automatizados Visíveis** | Sem evidência de cobertura de testes | Estratégia de testes: unitários para regras de negócio, integração para pipeline |
| 13 | **API Pública / SDK** | Sem API documentada para integrações externas | OpenAPI spec + SDK para automações de terceiros |
| 14 | **Importação/Exportação de Dados** | Sem mecanismo de migração de/para outras ferramentas | Import/Export de projetos, tarefas e contratos (JSON/CSV) |
| 15 | **Favoritos e Atalhos** | Sem personalização de acesso rápido | Bookmarks de projetos, tarefas e contratos mais acessados |
| 16 | **Modo Offline / Resiliência de Rede** | Pipeline depende de provedores de IA online | Graceful degradation com cache local quando IA indisponível |
| 17 | **Internacionalização (i18n)** | Sem menção a suporte multi-idioma | Preparar arquitetura para i18n se houver plano de expansão global |
