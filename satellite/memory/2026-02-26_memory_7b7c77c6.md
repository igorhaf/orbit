# Plataforma de Orquestração de IA com Análise de Código, RAG e Governança de Conhecimento

## O Que Faz

A plataforma automatiza a análise de bases de código usando inteligência artificial, selecionando automaticamente as partes mais relevantes antes de processá-las. Ela constrói e mantém bases de conhecimento reutilizáveis que consolidam aprendizados sobre arquitetura, padrões, regras de negócio e tecnologia de cada projeto.

## Capacidades Principais

**Análise Inteligente de Código**
O sistema avalia arquivos por relevância conceitual antes de enviá-los para análise. Prioriza automaticamente código de lógica de negócio (validações, regras, políticas) em detrimento de código utilitário, reduzindo custo de processamento sem perder contexto crítico.

**Controle de Custo Automático**
Bloqueia execuções quando o orçamento de IA é atingido, protegendo a organização de gastos inesperados. O controle ocorre antes mesmo das chamadas ao provedor de IA serem feitas.

**Validação e Reprocessamento Automático**
A saída gerada é validada automaticamente. Se falhar, o sistema tenta processar novamente sem intervenção manual.

**Base de Conhecimento Estruturada**
Transforma análises em wiki organizada por categorias: stack tecnológica, regras de negócio, funcionalidades, resultados de scans e padrões arquiteturais. Cada página recebe identificador único por projeto com verificação automática de duplicatas.

**Extração de Padrões Reutilizáveis**
Identifica padrões de código compartilhados entre arquivos (estruturas comuns, dependências, assinaturas de funções). Padrões são marcados com nível de confiança — apenas aqueles que aparecem de forma consistente em múltiplos arquivos são considerados de alta confiança.

**Busca Semântica de Conhecimento**
Integra busca vetorial para encontrar documentação e código similar, permitindo que análises aproveitem conhecimento prévio do projeto.

**Entrevistas Estruturadas**
Coleta informações através de diálogos estruturados que constroem contexto gradualmente para alimentar análises subsequentes.

## Regras de Governança

- Limite máximo de 50 especificações técnicas por projeto para evitar fragmentação de conhecimento
- Limite configurável de arquivos enviados para análise por execução, controlado por projeto
- Padrões extraídos do código exigem mínimo de 75% de similaridade entre arquivos para serem considerados de alta confiança
- Busca semântica retorna resultados apenas acima do limiar de 70% de similaridade
- Análise de documentação e código é feita em fases separadas com limites distintos
- Projetos em status rascunho recebem processamento diferenciado
- Cache semântico de prompts considera dois prompts equivalentes apenas com 95% de similaridade

## Impacto Operacional

O sistema cria um ciclo contínuo de aprendizagem onde análises anteriores informam análises futuras, reduzindo reprocessamento. A governança automática de custo elimina surpresas orçamentárias enquanto a modulação por relevância garante que recursos sejam gastos em decisões críticas. A estruturação do conhecimento em wiki reutilizável transforma análises pontuais em ativos organizacionais persistentes, criando memória institucional sobre arquitetura e padrões do código.
