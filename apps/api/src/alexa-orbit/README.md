# Alexa Orbit

Custom Skill **Orbit**, invocation **orbit**, locale **pt-BR**.

```text
Alexa, abra Orbit.
Orbit: Orbit aberto. Você pode adicionar uma tarefa, uma compra ou um compromisso.
Usuário: Adicione café nas compras.
Orbit: Adicionei café às compras.
```

[Configuração, segurança, modelo e validações](../../../../docs/plugins/alexa-orbit.md).

O modelo para importar no Alexa Developer Console está em `alexa/pt-BR.json`. As configurações ficam no painel do plugin. O plugin inicia desativado, não contém destinos fictícios e não cria infraestrutura externa.
